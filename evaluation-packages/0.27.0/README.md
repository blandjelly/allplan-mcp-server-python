## Candidate scope

- Attribute binding checks a bounded set of name spellings: supplied spelling, trimmed NFC, first-character uppercase, all uppercase and all lowercase. Each successful variant must round-trip through the actual project name and ID. Case-fold-equivalent results are accepted only when they resolve to one ID; ambiguity fails closed. There is no fuzzy lookup or catalog scan. `model_edit` uses the shared resolver. The read-only `attribute_name` probe retains exact lookup first and invokes fallback only after a `ValueError` or `TypeError` lookup miss, addressing the lowercase `mcp_qa_mark` case while preserving the canonical project name and ID.
- Native Wall material preview separates an observed old material value from the evidence needed to preserve the Wall. A blocked operation can retain the old value as `observed`, with `reason=native_material_preservation_unavailable` and a bounded observation diagnostic. `criteria.required_field_failures` reports unreadable required destination fields only; predicate failures remain in `report.criterion_failures`. The new `criteria.operation_eligibility_failures` currently reports Wall material preservation blockers and can be populated while the destination-field failures list is empty.
- Preservation requires a stable bounded child enumeration with exactly one direct `WallTier_TypeUUID` child, lineage `[tier, Wall root]`, no children under that tier, and no other Wall children. A `WindowDoor_TypeUUID` child reports `wall_material_openings_unsupported`; every other child type, including unknown Door/Window/Macro adapters, reports `wall_material_child_type_unsupported`. Bounded component read failures expose stable stage/error-type diagnostics, without native exception text. A readable material alone does not authorize a write or satisfy post-write preservation readback.
- The candidate adds no new native material-write eligibility case, selection support, date/vector/object codecs, or native Undo evidence. Existing write guards, revalidation, journaling, readback and unknown-result safeguards remain required.
